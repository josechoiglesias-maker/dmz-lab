# dmz-lab
laboratorio de dmz con packet tracer
Alumno Jose Manuel Calvo.
Objetivos del laboratorio

El objetivo de este laboratorio fue diseñar e implementar una arquitectura de red con una zona desmilitarizada (DMZ) utilizando un router Cisco ISR, 
aplicando NAT y listas de control de acceso (ACL) para controlar y restringir el tráfico entre la red interna (LAN), la DMZ y la red externa (Internet), 
garantizando así un entorno seguro.
